# 策略牌手册

策略牌是一次性战术资源。开局开启策略时，每名玩家从三张候选牌中选择一张；战役模式还会显示三张公共市场牌。每个地图回合最多购买一张，最多同时持有三张，不能重复持有同名策略。刚购买的牌在购买者下一个地图回合解锁，市场每三轮整体刷新。

战役策略每个地图回合最多使用一次，交锋策略每方每次交锋最多使用一次。使用后的策略进入弃牌堆。

## 市场与使用提示

- 购买策略不消耗主要行动，但会消耗表中所列补给。
- 战役策略只能在地图阶段发动；交锋策略只能在双方部署完成后的战术窗口或反击阶段发动。
- 使用策略前会弹出确认窗口（显示名称、阶段、完整效果与目标据点），医疗分队除外——它自带选牌流程。
- 需要选择据点的策略只有全域侦察、起义烽火、经济封锁、焦土政策和迁都；确认窗口只显示与当前策略相关的据点，全局策略（如征召令、国际援助、和平谈判、经济间谍）不会读取当前地图焦点。
- “潜伏密探”只让使用者查看一张暗牌；“火力侦搜”和“全域侦察”会真正翻开牌，双方都能看到。
- “闪电战”不能在己方被压制时使用；它用于锁定已经取得的优势。
- “停火谈判”是交锋策略（立即结束当前交锋），“和平谈判”是战役策略（未来 2 个完整回合双方停战），两者不要混淆。
