# 暗线战争 · Shadowline War

独立实现的 Three.js 网页卡牌战场游戏。所有运行资源均已包含，运行时不需要互联网，也无需 npm install。

## 立即游玩

首选：直接双击 **暗线战争.html**，无需安装任何依赖，也无需终端。单文件和服务器版使用不同浏览器来源，因此存档彼此独立。修改源码后执行 `node build.mjs` 重建单文件。

也可以在 Windows 双击 **启动游戏.cmd**。它会寻找系统 Node.js 或本机 Codex 自带的 Node.js，在服务器就绪后打开浏览器。

其他平台：安装 Node.js 20+，在本目录运行 `node server.mjs`，打开 http://127.0.0.1:4173 。关闭终端即停止服务。端口被占用时可设置环境变量 PORT。

## 游戏内容

- 三张战场：双都对峙（参考指定地图拓扑）、裂谷防线、灰烬环岛。
- 人机对战：新兵与老兵两种策略风格；AI 不读取对方隐藏牌的点数、花色或洗牌状态。
- 同机双人对战：每次换人时遮蔽手牌，准备就绪后开始计时。**不是两台设备联网模式**。
- 初始策略三选一，13 种战役／交锋策略；每张一次性使用。
- 战役夺取首都模式，以及不含地图、驻军、补给的经典模式。
- 30／60／120 秒或无限时、先行军团、随机种子、回合上限、策略开关。
- 暂停、规则手册、公开牌查询、音效开关、本浏览器自动存档。
- WebGL 不可用时降级为可操作的二维战术地图。

## 操作

地图阶段：点击目标据点。占领中立点需先点击一张手牌作为驻军；进攻敌方则进入交锋。

部署阶段：点击手牌依次循环 **明牌 → 暗牌 → 取消**。每方 1–3 张，至少 1 张明牌；进攻方明牌必须严格压过防守方。

对抗阶段：点击自己战线上的暗牌，选择翻开 1 或 2 张，或撤退。防守方平手即可赢，进攻方必须严格压过。详细规则和扩展说明均在游戏内“规则”。

## 原文歧义和本作扩展

仅参考用户指定的三个文件，没有读取或复用原仓库的其他逻辑或界面：

- https://github.com/lordstone/my_card_game/blob/main/instruction.md
- https://github.com/lordstone/my_card_game/blob/main/src/strategyCards/data/basic.json
- https://github.com/lordstone/my_card_game/blob/main/src/maps/data/duel_capital.json

交锋采用持续翻牌循环：首次进攻部署不会立即获胜。翻牌反超后，若对方仍有战线暗牌，轮到对方反击；仍被压制且有暗牌时继续翻牌或撤退。被压制方没有战线暗牌或撤退时才结算。平手由防守方占优，但不跳过另一方剩余暗牌的反击机会。闪电战与停火按各自效果结束交锋。

组合牌型必须恰好三张明牌；两张相同点数按高牌计算。含王只按高牌处理，王不参与任何组合。A 不能环绕为 Q-K-A。

原 MVP 不定义地图、资源或特殊能力。战役模式扩展：每方开局12张中抽1张为首都驻军；地图回合一次主行动；相邻占领需驻军牌；驻军防守时回手部署；每点产1补给、油田2，每2点补1张；交锋后补至12。医疗从己方公开牌恢复，起义生成额外A。完整细则见游戏手册。经典模式可关闭策略，单独体验54张牌的核心规则。

## 验证

`node tests/engine.test.mjs` 或 `npm test`。

已通过25组规则与事件测试：
- 全部24,804种三张牌组合的分类数量；
- 非法部署、严格比较、平手、防守翻牌、撤退、收牌和临时晋升清除；
- 13种策略的前置条件和效果，地图邻接、首都胜利、牌数守恒；
- 超时行动、存档恢复与隐藏信息隔离；
- 144场跨地图、规则、策略开关、AI风格的完整对局，共11,671次合法行动。

已在 Chrome 中完成 7 组真实浏览器交互回归：AI 入侵与计时暂停、新牌展示、策略目标选择、驻军查看、同机交接保密、闪电战窗口、AI 反超后玩家继续翻牌；覆盖 1440px 桌面与 390px 手机宽度，无页面脚本错误。测试覆盖这些场景，不代表绝对没有其他 bug。

浏览器测试导出 tests/browser.test.mjs 的 browserChecks(browser, url)，传入 Playwright 的 Chromium Browser 实例即可运行；需先启动本地服务器。独立 HTML 校验：npm run test:bundle。

## 项目结构

- `src/engine.js`：纯状态机、牌力、策略、AI；非法行动不改变原状态。
- `src/data.js`：地图、策略和选项。
- `src/app.js`：界面、选牌、暂停、计时、存档。
- `src/battlefield.js`：Three.js立体战区，故障时降级。
- `src/style.css`：战术界面与自适应布局。
- `vendor/`：Three.js r180官方构建及MIT许可证。
- `server.mjs`：仅监听127.0.0.1的无依赖静态服务器。
- `tests/engine.test.mjs`：规则与完整对局测试。

Three.js来源：https://github.com/mrdoob/three.js/tree/r180/build 。许可证保留于 vendor/THREE-LICENSE.txt。无遥测，无远程资源，无外部字体。存档属于本机浏览器的数据；更换端口或浏览器会使用独立存档。

## 1.1 试玩修复

入侵、占领、部署、翻牌、结算、补给和新牌均逐条展示，默认每条 3 秒；高级选项可改为 1 或 5 秒，也可点击继续。动画和暂停期间不消耗行动时限，AI 等待展示结束。新牌加入手牌后标记「新」。

进攻部署成功后，如持有交锋策略，会进入战术窗口，可先使用策略再让防守方反击。闪电战只允许己方占优时使用，修复原先只能被压制时使用、反而让对手获胜的问题。

驻军独立于手牌和公开牌堆计数。点击军团面板查看各据点驻军。遭入侵时驻军回到防守方手牌；守住据点且原驻军仍在手牌时优先让原牌归队，避免无故换成别的牌。否则从该方公开牌堆或手牌补充驻军。战斗动画会说明这些移动。

## 1.1.1 翻牌反击修复

修复对手翻牌反超后立即判负的问题。有战线暗牌的一方会获得反击机会，双方可以连续反超；晋升、增援与侦察后的比较也使用相同流程。只有被压制方没有战线暗牌、撤退，或使用立即结算的策略时才结束交锋。
